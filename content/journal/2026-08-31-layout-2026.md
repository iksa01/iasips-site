Nothing outside this panel has moved. The graph paper, the masthead, the engraved cards, the colophon are exactly as Simon Collison drew them in 2010. What has changed is the part you actually read, and the change is almost entirely **space, scale and the grid** — not colour, not motion, not JavaScript.

::: side
Sidenotes sit out here, beside the sentence that needs them, instead of waiting at the foot of the page. On a narrow screen they fold back into the text with a hairline down the left.
:::

Josh Comeau's site — the one that reads as current — is doing three things this column now does. His text sits in a column of about 42rem, roughly sixty-five characters, because that is where the eye is comfortable. His type grows a little on a large screen instead of staying at a fixed size. And his images and demos **break out** of that column when they need width, rather than being squeezed into it.

::: side
v4's column was 516px of 15px Times — narrow even in 2010, because it had a sidebar to accommodate. Here the sidebar becomes the sidenote margin, so the column can breathe.
:::

The old typographic journals did the same thing, incidentally. A printed miscellany has a narrow measure, notes in the margin, and a plate that spans the full page when the plate deserves it. This is not a modern invention so much as a modern rediscovery.

## What breaking out looks like

A table, a code block or a picture can leave the reading column and take the whole width. Nothing else changes: the rules stay hairlines, the code stays in its 8-bit face.

::: bleed
```js title="the whole width, when it earns it"
// Three tracks: sidenote margin | reading column | room to break out.
div#content-pri {
  display: grid;
  grid-template-columns: 190px minmax(0, 40em) 1fr;
  column-gap: 28px;
}
div#content-pri > *      { grid-column: 2; }   /* everything reads here      */
div#content-pri > aside  { grid-column: 1; }   /* except notes, which sit out */
div#content-pri > .bleed { grid-column: 1/-1; } /* and plates, which span     */
```
:::

## What is doing the work

Fluid type through `clamp()`, so the body sits at 15px on a laptop and grows toward 17px on a large screen without a breakpoint. Line height at 1.62 rather than 1.47. Headings that break evenly because of `text-wrap: balance`. Forty-eight pixels of air above a section head instead of thirty.

::: side
Every one of these is a build-time or CSS feature. The page still ships zero JavaScript, has no dark mode, and animates nothing.
:::

::: note What this does not take from Josh's site
Dark mode, interactive widgets, motion on scroll, a second hue, a sticky sidebar, a newsletter box. Those are the things that would stop this looking like a printed miscellany — and they are all forbidden by §10 and §12 anyway.
:::

Compare this against the older entry and decide which one you want the journal to read like. If it is this one, it becomes the default for essays and the change goes into DESIGN.md as a new section; the shell does not move either way.
